# DAW - Desarrollo de Aplicaciones Web (Curso 2026)

Este repositorio está dedicado al almacenamiento, organización y gestión de las prácticas, tareas y laboratorios desarrollados a lo largo del curso académico 2026 en la asignatura de **Desarrollo de Aplicaciones Web (DAW)**.

##  Estructura del Repositorio

El proyecto se organiza de manera modular por laboratorios y asignaciones académicas:

* **`lab06/`**: Laboratorio enfocado en el desarrollo backend, diseño de bases de datos y modelado entidad-relación utilizando herramientas de Django.
* **`README.md`**: Documentación principal del repositorio (este archivo).

## Tecnologías y Herramientas Utilizadas

* **Lenguaje de Programación:** Python 3.x
* **Framework Principal:** [Django](https://www.djangoproject.com/) (diseño de aplicaciones web y ORM para bases de datos).
* **Gestión de Modelos:** Herramientas de generación y visualización de modelos Entidad-Relación (E-R).
* **Control de Versiones:** Git y GitHub.
